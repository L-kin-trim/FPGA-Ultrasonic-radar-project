# 超声波雷达系统可做功能清单

目标：基于当前 FPGA + 上位机架构，给出可增量实现的功能点，便于排期与迭代。

## 上位机功能
- [ ] 参数一键下发：量程/测距时间/步进/最小角度/最大角度统一下发
- [ ] 参数回读与校验：显示 FPGA 实际生效参数并做一致性提示
- [ ] 扫描模式切换：往返扫描/单向扫描/固定角度点测
- [ ] 自动量程：根据当前最大回波动态调整显示比例
- [ ] 数据滤波：中值/平均滤波减少毛刺点
- [ ] 数据记录：保存 CSV/Excel 并支持回放
- [ ] 目标跟踪：标记最近 N 帧稳定目标并显示轨迹
- [ ] 多设备支持：同时连接多路串口并分屏显示
- [ ] UI 主题与语言：暗色/亮色切换与英文界面

## FPGA/串口协议
- [ ] 协议加校验：CRC8 或简单校验和
- [ ] 下发确认：FPGA 回 ACK/NACK，支持重发
- [ ] 批量配置帧：一次性携带所有参数，减少串口开销
- [ ] 运行状态上报：系统启动/测距超时/回波异常标志

## 测距与控制逻辑
- [ ] 可配置回波超时阈值并上报超时次数
- [ ] 扫描边界平滑：到边界时可停顿或缓速
- [ ] 伺服标定模式：0°/90°/180°快速校准
- [ ] 单点多次测量：同角度多次取中值

## 硬件扩展
- [ ] 双传感器阵列：左右两路超声波交替测距
- [ ] 供电监测：低电压提示与保护
- [ ] 蜂鸣器/LED 状态指示
- [ ] 机械限位检测

## 测试与诊断
- [ ] 串口自检：环回测试与误码统计
- [ ] 仿真激励脚本：自动生成回波模型
- [ ] 日志等级：INFO/WARN/ERROR 可切换

## 创新点方向（可用于申报/答辩）
- [ ] 自适应扫描密度：近处密集、远处稀疏，动态调整步进与停留时间
- [ ] 温度补偿测距：增加温度传感器修正声速，提高精度
- [ ] 动态目标检测：帧间差分，标记运动目标与速度趋势
- [ ] 多帧融合热力图：扇区累计显示障碍概率/占据度
- [ ] 伺服零位自校准：通过参考挡板或限位自动修正偏差
- [ ] 目标稳定性评估：基于 MAD(中位数绝对偏差) 计算波动度，按 CV_robust=1.4826*MAD/median 映射为可信度评分
- [ ] 传感器融合：IMU/编码器 + 超声波实现相对位姿感知
- [ ] 远程监控/云端：数据上传与网页端查看控制
- [ ] 低功耗策略：空闲自休眠、按需唤醒扫描
- [ ] 异常诊断：回波缺失/过饱和/抖动自动告警
