# 超声波雷达系统

基于FPGA的超声波雷达系统，使用HC_SR04超声波传感器和SG90舵机实现0-180度扫描测距。

## 功能特性

1. **HC_SR04超声波测距**
   - 精度：1mm
   - 最大量程：3m
   - 50MHz时钟驱动

2. **SG90舵机控制**
   - 角度范围：0-180度
   - 循环扫描：0° → 180° → 0°
   - 可配置旋转步进角度（默认10度）

3. **UART串口通信**
   - 波特率：115200
   - 数据格式：D距离A角度\n
   - 例如：D1234A90\n 表示距离1234mm，角度90度

4. **上位机程序**
   - 实时显示雷达扫描界面（支持180°/360°视图切换）
   - 接收并显示串口数据
   - 参数设置、自动量程、多次测量、蜂鸣器报警
   - 目标稳定性评估（MAD可信度评分）
   - 伺服标定（0°/90°/180°）

## 硬件连接

### HC_SR04超声波传感器
- `trig`: 连接到FPGA输出引脚（触发信号）
- `echo`: 连接到FPGA输入引脚（回波信号）
- `VCC`: 5V
- `GND`: 地

### SG90舵机
- `PWM`: 连接到FPGA输出引脚（PWM控制信号）
- `VCC`: 5V
- `GND`: 地

### UART接口
- `tx_out`: 连接到FPGA输出引脚（串口发送）
- `rx_pin_in`: 连接到FPGA输入引脚（串口接收，可选）
- 通过USB转串口模块连接到PC

## 使用方法

### 1. FPGA综合与实现

1. 在FPGA开发工具（如Vivado、Quartus等）中创建新项目
2. 添加所有RTL文件到项目
3. 设置顶层模块为 `radar_top`
4. 配置引脚约束文件
5. 综合、实现并生成比特流文件
6. 下载到FPGA开发板

### 2. 运行上位机程序

1. 安装Python依赖：
```bash
pip install -r requirements.txt
```

2. 运行GUI程序：
```bash
python python/radar_gui.py
```

3. 在GUI中：
   - 选择正确的串口
   - 设置波特率为115200
   - 点击"连接"按钮
   - 观察雷达扫描界面和数据接收

### 3. 打包为可执行.exe

在`Code/python`目录下执行：

```bash
build_exe.bat
```

生成的可执行文件位于`Code/python/dist/radar_gui.exe`。

### 3. 参数设置

在上位机界面中可以设置以下参数与功能：

- **最大量程**：设置雷达显示的最大量程（1-3000mm）
- **测距时间**：设置每次测距的超时时间（默认0.5秒）
- **旋转角度**：设置舵机每次旋转的步进角度（默认10度）
- **最小/最大角度**：限制扫描角度范围
- **扫描模式**：往返扫描 / 单向扫描 / 固定角度点测
- **自动量程**：根据当前最大回波动态调整显示量程
- **多次测量**：同一角度多次测量并取均值
- **蜂鸣器报警**：量程内检测到物体触发蜂鸣器
- **目标稳定性评估**：基于MAD计算可信度评分（可勾选）
- **视图切换**：180°/360°雷达显示
- **目标点大小**：滑条控制红点标志大小

设置后会通过UART下发到FPGA，FPGA收到后会动态更新测距超时与步进角度。

## 工作原理

### 测距流程

1. 发送10us的trig触发脉冲
2. 等待echo信号上升沿
3. 测量echo高电平持续时间
4. 计算距离：距离(mm) = (echo时间 / 294) 
   - 其中294是每毫米对应的时钟周期数（50MHz时钟下）

### 扫描流程

1. 设置舵机角度（0-180度循环）
2. 等待舵机稳定（约100ms）
3. 触发超声波测距
4. 等待测距完成
5. 通过UART发送距离和角度数据
6. 等待间隔时间（默认0.5s）
7. 更新角度，重复步骤1

### 数据格式

UART发送的数据格式为：`D距离A角度\n`

- `D`: 距离标识符（ASCII码0x44）
- 距离：1-4位数字的ASCII码（例如：1234 → '1''2''3''4'）
- `A`: 角度标识符（ASCII码0x41）
- 角度：1-3位数字的ASCII码（例如：90 → '9''0'）
- `\n`: 换行符（ASCII码0x0A）

示例：`D1234A90\n` 表示距离1234mm，角度90度

### 参数下发格式（PC -> FPGA）

- `Sxxx\n`：设置舵机步进角度（1-180），`xxx`为3位数字
- `Tmmmmm\n`：设置测距时间（1-60000ms），`mmmmm`为5位数字
- `Lxxx\n`：设置最小角度（0-180）
- `Hxxx\n`：设置最大角度（0-180）
- `M0/1/2\n`：扫描模式（0往返/1单向/2固定角度）
- `R0/1\n`：自动量程开关
- `E0/1\n`：多次测量开关
- `Nxx\n`：多次测量次数（01-20）
- `Cxxx\n`：伺服标定角度（0-180）
- `Gxxxx\n`：量程阈值（1-3000mm）
- `B0/1\n`：蜂鸣器报警开关

示例：

- `S010\n`：步进角度10°
- `T00500\n`：测距时间500ms

FPGA使用测距时间作为测距超时和扫描间隔。

## 技术参数

- **时钟频率**：50MHz
- **UART波特率**：115200
- **测距精度**：1mm
- **最大量程**：3000mm（3m）
- **角度范围**：0-180度
- **默认旋转步进**：10度
- **默认测距超时**：0.5秒

## 注意事项

1. 确保HC_SR04和SG90的供电电压为5V
2. FPGA的I/O电压需要与传感器兼容
3. 串口连接时注意TX/RX方向
4. 如果测距失败，检查传感器连接和供电
5. 舵机旋转时注意负载，避免堵转

## 故障排除

### 无法接收数据
- 检查串口连接和波特率设置
- 确认FPGA已正确下载比特流
- 检查UART TX引脚连接

### 测距数据异常
- 检查HC_SR04的trig和echo连接
- 确认传感器供电正常
- 检查是否有物体遮挡传感器

### 舵机不旋转
- 检查SG90的PWM信号连接
- 确认舵机供电正常
- 检查PWM信号是否正确生成
